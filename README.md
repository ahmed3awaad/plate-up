# Plate Up

A gym progressive-overload tracker. Snap a photo of the machine, tap the suggested weight, rate how hard it felt, and Plate Up tells you when to add weight and how much.

- One file: `index.html` (no build step, no dependencies)
- Data is saved in the browser on your device (localStorage)
- Coaching uses double progression: add reps until you hit the top of your rep range, then add weight
- Training plans: Push · Pull · Legs, Upper · Lower, Full Body or your own; the home screen shows today's workout

## Run it

Open `index.html` in a browser, or turn on GitHub Pages for this repo (Settings → Pages → Deploy from branch → `main`) and open the link on your phone.
